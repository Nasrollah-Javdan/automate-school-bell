# DS School Bell — زنگ مدرسه DS

نرم‌افزار دسکتاپ سبک، سریع و کاملاً محلی برای اجرای خودکار زنگ‌های مدرسه روی ویندوز ۱۰ و ۱۱.

> **Simple enough for a school employee, powerful enough to run the entire
> school bell schedule reliably.**

<div dir="rtl">

## معرفی

کاربر اصلی فقط شش کار می‌خواهد انجام دهد: برنامه زنگ‌ها را تعریف کند، ساعت‌ها را
ببیند، سیستم را فعال کند، زنگ‌ها خودکار پخش شوند، صدا را تست کند و در صورت نیاز
برنامه را تغییر دهد. کل رابط کاربری حول همین شش کار ساخته شده است.

## قابلیت‌ها

### صفحه اصلی (Dashboard)

- وضعیت لحظه‌ای سیستم: فعال / متوقف / غیرفعال
- ساعت بزرگ و تاریخ کامل شمسی + میلادی + روز هفته
- **زنگ بعدی** به همراه شمارش معکوس (`00:12:46`)
- چهار کنترل سریع: شروع · توقف · تست زنگ · غیرفعال‌سازی
- جدول «برنامه امروز» با وضعیت هر زنگ: پخش شد / بعدی / رد شد

### برنامه زنگ‌ها

- افزودن، ویرایش، حذف و تغییر ترتیب زنگ‌ها
- فعال یا غیرفعال کردن هر زنگ به‌صورت مستقل
- انتخاب ساعت، عنوان، یادداشت و فایل صوتی برای هر زنگ
- چند برنامه مستقل (مثلاً برنامه عادی و برنامه امتحانات) با انتخاب برنامه فعال
- انتخاب روزهای فعال هفته برای هر برنامه (شنبه تا جمعه)

### فایل‌های صوتی

- پشتیبانی از `MP3`، `WAV`، `OGG` و `FLAC`
- دو روش افزودن: کپی به پوشه برنامه (پیشنهادی) یا استفاده از فایل بیرونی
- صدای متفاوت برای هر زنگ، به‌علاوه صدای پیش‌فرض
- بلندی صدا به‌صورت جداگانه برای هر فایل + بلندی کلی
- پخش آزمایشی، توقف و خواندن مدت فایل
- تشخیص فایل گم‌شده با پیام واضح و امکان انتخاب دوباره فایل

### تعطیلی‌ها

- ثبت روزهای تعطیل با تقویم شمسی
- در روز تعطیل هیچ زنگی پخش نمی‌شود
- نمایش «تعطیلی بعدی» و شمار روزهای باقی‌مانده

### گزارش فعالیت

- ثبت پخش زنگ‌ها، تغییر وضعیت سیستم، تعطیلی‌ها و خطاها
- ذخیره‌سازی دائمی با نگهداری ۵۰۰ رکورد آخر
- فیلتر بر اساس سطح (موفق / هشدار / خطا)
- متن گزارش‌ها هم به فارسی و هم به انگلیسی نمایش داده می‌شود

### تنظیمات

| بخش | موارد |
| --- | --- |
| عمومی | زبان، اجرا با ویندوز، اجرای کمینه، کمینه و بستن به نوار وظیفه |
| صدا | بلندی کلی، صدای پیش‌فرض، پخش آزمایشی |
| نمایش | پوسته (روشن / تاریک / مطابق سیستم)، اندازه رابط (۱۰۰٪ تا ۲۰۰٪) |
| سیستم | نسخه پشتیبان، بازیابی، بازنشانی کامل، باز کردن پوشه اطلاعات |

## زبان و راست‌چین

برنامه به‌طور کامل دو زبانه است و هیچ متنی در کد نوشته نشده است. هر ۳۴۱ کلید ترجمه
در `src/i18n/` نگهداری می‌شود و یک تست واحد تضمین می‌کند که هر دو زبان دقیقاً
کلیدهای یکسانی داشته باشند.

- **فارسی** — چینش راست‌به‌چین واقعی، فونت وزیرمتن (همراه برنامه)، تاریخ شمسی و
  ارقام فارسی
- **English** — چینش چپ‌به‌راست، ساعت ۱۲ ساعته، تاریخ میلادی

تغییر زبان بلافاصله اعمال می‌شود. جهت چیدمان با ویژگی‌های منطقی CSS
(`margin-inline-start` و …) نوشته شده است، بنابراین هر دو جهت از یک شیوه‌نامه
استفاده می‌کنند.

## موتور زمان‌بندی

دقت، مهم‌ترین ویژگی این برنامه است:

- یک تایمر دقیق برای **میلی‌ثانیه دقیق** زنگ بعدی تنظیم می‌شود (نه `setInterval`)
- در هر بیدار شدن، ساعت سیستم دوباره خوانده می‌شود؛ بنابراین تغییر ساعت، حالت
  خواب و بیداری (Sleep/Resume) و تغییر ساعت تابستانی خودکار مدیریت می‌شوند
- هر زنگ یک شناسه یکتا می‌گیرد، مثلاً `2026-09-27_09:30_b1`، و در فایل ذخیره می‌شود.
  به همین دلیل **یک زنگ هرگز دوبار پخش نمی‌شود**، حتی اگر برنامه چند بار
  بازمحاسبه شود یا ری‌استارت شود
- اگر برنامه دیرتر از حد مجاز باز شود، زنگ‌های از دست رفته طبق تنظیم کاربر
  «نادیده گرفته می‌شوند» یا «اگر اخیر باشند پخش می‌شوند»
- حداکثر ۱۵ دقیقه بعد از هر بیدار شدن، وضعیت دوباره بررسی می‌شود تا هیچ شرایطی
  از قلم نیفتد

## ذخیره‌سازی

همه چیز محلی است و چیزی به اینترنت ارسال نمی‌شود.

- مسیر داده: `%APPDATA%\DS School Bell` (ویندوز)
- `state.json` — برنامه‌ها، زنگ‌ها، صداها، تعطیلی‌ها و تنظیمات
- `activity-log.json` — گزارش فعالیت
- `sounds/` — فایل‌های صوتی کپی‌شده
- **نوشتن اتمیک:** هر نوشتن ابتدا در فایل موقت انجام و سپس با `rename` جایگزین
  می‌شود. یک کپی `.bak` از آخرین نسخه سالم نگهداری می‌شود، بنابراین قطع برق یا
  بسته شدن ناگهانی هیچ تنظیمی را از بین نمی‌برد
- هر داده‌ای که از دیسک یا از فایل پشتیبان خوانده می‌شود، اعتبارسنجی می‌شود؛
  فایل خراب یا دستکاری‌شده هرگز باعث کرش نمی‌شود

## پشتیبان‌گیری

خروجی گرفتن یک فایل `DS-SchoolBell-Backup.json` شامل برنامه‌ها، زنگ‌ها، مسیر
فایل‌های صوتی، تعطیلی‌ها، تنظیمات، زبان و پوسته. بازیابی با یک کلیک و پس از
تأیید کاربر انجام می‌شود.

## میان‌برهای صفحه‌کلید

| کلید | کار |
| --- | --- |
| `Space` | شروع / توقف |
| `Ctrl + T` | تست زنگ |
| `Ctrl + ,` | تنظیمات |
| `Esc` | بستن پنجره |

میان‌برها هنگام تایپ در فیلدها غیرفعال می‌شوند و `Space` روی دکمه‌ها به همان
شکل معمولی کار می‌کند.

## توسعه

### پیش‌نیازها

- Node.js ۲۰ یا بالاتر
- Python ۳ (فقط برای بازتولید آیکون و صدای پیش‌فرض)

### نصب

```bash
npm install
```

### اجرا در حالت توسعه

```bash
npm run dev
```

### تست‌ها

```bash
npm test          # ۶۵ تست واحد: زمان، تاریخ شمسی، موتور زنگ، اعتبارسنجی
npm run test:e2e  # تست انتها‌به‌انتها داخل Electron (۵۵ بررسی)
```

تست انتها‌به‌انتها موتور زمان‌بندی، پخش صدای واقعی، ذخیره‌سازی، پشتیبان‌گیری،
ترجمه‌ها و پنجره را اجرا می‌کند.

### بررسی کیفیت

```bash
npm run typecheck   # TypeScript در دو محیط (main و renderer)
npm run lint        # ESLint
npm run format      # Prettier
```

### گرفتن اسکرین‌شات از رابط کاربری

```bash
npm run capture     # نمای فارسی/انگلیسی، روشن/تاریک، در اندازه‌های مختلف
```

تصاویر در پوشه `screenshots/` ذخیره می‌شوند.

## ساخت نسخه نهایی

### ویندوز (Installer)

```bash
npm run build:win
```

خروجی: `release/DS School Bell-Setup.exe`

Installer با NSIS ساخته می‌شود و شامل موارد زیر است:

- انتخاب پوشه نصب
- ساخت میان‌بر در دسکتاپ و منوی Start
- ورودی «Start with Windows» در رجیستری ویندوز
- uninstaller که تنظیمات کاربر را **پاک نمی‌کند** (تا برنامه‌های مدرسه از بین نرود)

> **نکته:** ساخت Installer ویندوز باید روی یک سیستم‌عامل ویندوز انجام شود.
> برای بررسی سریع روی سیستم لینوکس می‌توان از `npm run build:linux` استفاده کرد.

### لینوکس (AppImage)

```bash
npm run build:linux
```

## معماری

```
src/
├── main/                  فرایند اصلی — تمام منطق کسب‌وکار
│   ├── audio/             موتور صوتی: پروتکل اختصاصی + پنجره پنهان پخش
│   ├── scheduler/         موتور زنگ: تایمر دقیق، ثبت اجراها
│   ├── services/          تمام تغییرات وضعیت و عملیات سطح بالا
│   ├── storage/           ذخیره‌سازی اتمیک، کتابخانه صدا، پشتیبان
│   ├── system/            پوسته، اجرای خودکار، مدیریت خطا
│   ├── tray/              نوار وظیفه
│   └── window/            مدیریت پنجره
├── preload/               پل تایپ‌شده و امن بین main و renderer
├── renderer/              رابط کاربری React
│   ├── components/        اجزای UI و سیستم طراحی
│   ├── pages/             شش صفحه اصلی
│   ├── layouts/           چیدمان و ناوبری
│   ├── hooks/             قلاب‌های React
│   └── styles/            توکن‌های طراحی و شیوه‌نامه‌ها
├── shared/                کد مشترک و بدون وابستگی به Electron
├── i18n/                  ۳۴۱ کلید ترجمه فارسی و انگلیسی
├── types/                 قراردادهای داده و IPC
└── utils/                 تاریخ شمسی، زمان، شناسه
```

**اصل جداسازی:** رابط کاربری هیچ منطق کسب‌وکاری ندارد. موتور زنگ در فرایند اصلی
اجرا می‌شود، بنابراین حتی اگر رابط کاربری بسته، کند یا در حال بازسازی باشد،
زنگ‌ها همچنان پخش می‌شوند.

## امنیت

- `contextIsolation` و `sandbox` برای هر دو پنجره
- فقط `contextBridge` در اختیار رابط کاربری قرار می‌گیرد
- پروتکل صوتی اختصاصی فقط سه مسیر را سرو می‌کند: پوشه صداهای برنامه، فایل‌هایی که
  کاربر خودش انتخاب کرده، و صدای پیش‌فرض همراه برنامه
- ناوبری و پنجره‌های بیرونی مسدود شده‌اند
- ورودی‌ها پیش از ذخیره اعتبارسنجی می‌شوند
- حذف فایل صوتی فقط برای فایل‌هایی انجام می‌شود که خود برنامه کپی کرده است؛
  فایل‌های بیرونی کاربر هرگز حذف نمی‌شوند
